# Carvalho Gestão

Sistema interno da Construtora Carvalho para gestão integrada de obras e financeiro.

## Funcionalidades atuais

- painel geral com indicadores financeiros e operacionais;
- cadastro e acompanhamento das obras;
- ficha completa por obra;
- cronograma físico-financeiro;
- documentos, diário de obra, pendências e aditivos;
- compras, entregas, medições e faturamento;
- folha de pagamentos e alertas;
- identidade visual da Construtora Carvalho.

## Executar localmente

O projeto atual é uma aplicação web estática. Sirva a pasta `dist` com qualquer servidor HTTP local.
